# Taller de Programación Orientada a Objetos en JavaScript

## Descripción
Este proyecto contiene ejercicios prácticos de programación orientada a objetos (POO) en JavaScript, basados en situaciones de la vida cotidiana. Su objetivo es aplicar conceptos fundamentales mediante la creación de clases, objetos, métodos y validaciones.

## Objetivo
Desarrollar habilidades de programación utilizando encapsulamiento, herencia, polimorfismo, arreglos, manejo de errores y pruebas de funcionamiento.

## Ejercicios realizados
1. **Cuentas bancarias:** administración de cuentas, saldos y retiros.
2. **Productos y carrito de compras:** cálculo de precios y control de productos.
3. **Sistema de transporte:** administración de vehículos y cálculo de costos de viajes.
4. **Citas médicas:** registro y validación de citas.
5. **Nómina de empleados:** cálculo de salarios y total de nómina.
6. **Biblioteca:** registro, préstamo y devolución de recursos.
7. **Restaurante:** administración de productos y cálculo de pedidos.
8. **Servicios de reparación:** registro de servicios y cálculo de costos.
9. **Reservas:** administración de reservas de hoteles y tours.
10. **Adopción de mascotas:** registro de adopciones y control de cuidados.

## Conceptos aplicados
- **Clases y objetos:** representación de elementos de cada sistema.
- **Encapsulamiento:** protección de datos mediante campos privados cuando corresponde.
- **Herencia:** reutilización de características y métodos de una clase padre en clases hijas.
- **Polimorfismo:** implementación de métodos con comportamientos diferentes en las clases derivadas.
- **Arreglos:** administración de varios objetos y registros.
- **Validación de datos:** comprobación de información antes de ejecutar operaciones.
- **Manejo de errores:** uso de `throw`, `try` y `catch` para detectar y controlar situaciones inválidas.

## Pruebas
Se ejecutaron los ejercicios con Node.js para comprobar sus resultados y las validaciones. Se probaron situaciones válidas e inválidas, como precios incorrectos, datos faltantes, registros duplicados, recursos inexistentes y operaciones no permitidas.

## Tecnologías utilizadas
- JavaScript
- Node.js
- Visual Studio Code
- Git y GitHub

## Cómo ejecutar los ejercicios
1. Instalar Node.js.
2. Descargar o clonar este repositorio.
3. Abrir la carpeta del proyecto en Visual Studio Code.
4. Abrir una terminal en la carpeta del proyecto.
5. Ejecutar el archivo del ejercicio que se desea probar con el comando:

```bash
node ejercicio1-cuentas.js
```

Cambiar el nombre del archivo para ejecutar otro ejercicio.
